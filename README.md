# 键位调试台

给键盘固件用的浏览器调试页。默认是一台 ANSI 104 全尺寸键盘。

按键时键帽会亮，矩阵里对应的格子会亮，下面记下键值、HID 用途码和按下时长。松开短于 15ms 会标成抖动。Fn / Fn2 是手动切换的逻辑层，用来看和改键值，再导出 QMK 风格的 C 数组。

矩阵行列是逻辑坐标，不是你的原理图。选中一个键后可以改行、列和灯序，改完再导出。

## 打开

```bash
python3 -m http.server 8765
```

浏览器打开 `http://localhost:8765`。

直接按键盘就能看高亮。连接真实 HID 报文需要 Chrome 或 Edge，点「连接键盘」。这个页面不会把键值写进键盘。
